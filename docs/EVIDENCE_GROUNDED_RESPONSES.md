# Evidence-Grounded Responses

Jawaban riset harus berbasis evidence yang bisa dijelaskan.

## Format Jawaban

Research brief sebaiknya memuat:

- Ringkasan jawaban.
- Evidence yang dipakai.
- Confidence.
- Unknowns/gaps.
- Source limitations.
- Next recommended checks.

## Klaim

- Klaim dari project docs ditandai sebagai kondisi repo lokal.
- Klaim API/provider terbaru harus diberi freshness warning jika belum diverifikasi.
- Blog/forum dianggap source dengan credibility lebih rendah.
- Jika evidence tidak cukup, jawab `unknown`, bukan mengarang.

## Anti-Hallucination

Dilarang:

- Membuat nama source palsu.
- Mengutip panjang dari source berhak cipta.
- Menjawab pasti dari source yang tidak jelas.
- Menyembunyikan gap atau konflik evidence.
