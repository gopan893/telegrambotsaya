# Long Message Policy

## Limit
- Default max: 3500 chars per part
- Absolute Telegram limit: 4096 chars
- Prefer split di batas paragraf

## Part Headers
- "Bagian 1/3"
- "Bagian 2/3"
- "Bagian 3/3"

## Code Block Safety
- Code block tidak dipecah jika muat
- Jika terlalu panjang, split dengan continuation marker
- Tidak ada konten yang di-drop
