# Final Environment Checklist

## Required (must be configured)

- NODE_ENV
- PORT
- WEBHOOK_URL
- TELEGRAM_TOKEN
- OWNER_CHAT_ID
- ADMIN_IDS
- DASHBOARD_ADMIN_TOKEN
- STORAGE_DRIVER
- DATABASE_URL
- AI_PROVIDER

(Set the API key corresponding to AI_PROVIDER)

## Recommended (should be configured)

- REDIS_URL
- APP_PUBLIC_URL
- HEALTHCHECK_URL
- OBSERVABILITY_ENABLED
- COST_GOVERNANCE_ENABLED
- EXECUTOR_APPROVAL_REQUIRED
- EXTERNAL_WRITE_APPROVAL_REQUIRED
- INTEGRATION_EVAL_GATE_REQUIRED
- GITHUB_PUSH_APPROVAL_REQUIRED
- DEPLOY_APPROVAL_REQUIRED
- ROLLBACK_APPROVAL_REQUIRED
- AUTO_APPROVE_ENABLED (must be false)
- AUTO_RUN_ENABLED (must be false)
- SHELL_EXECUTOR_ENABLED (must be false)

## Optional (configure if needed)

- BOT_2_TOKEN, BOT_3_TOKEN, BOT_4_TOKEN (multi-bot)
- GITHUB_TOKEN, GITHUB_REPO, GITHUB_OWNER (GitHub Ops)
- RENDER_API_KEY, RENDER_SERVICE_ID, RENDER_DEPLOY_HOOK_URL (Render deploy)
- GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI (Google connectors)
- GMAIL_USER, CALENDAR_ID (Gmail/Calendar)
- CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_TUNNEL_ID (Cloudflare)
- SEARCH_API_KEY, WEATHER_API_KEY (tools/search/weather)
- OPENAI_API_KEY, ANTHROPIC_API_KEY, GOOGLE_GEMINI_KEY (AI providers)

## Dangerous Flags (must be false for production)

- AUTO_APPROVE_ENABLED
- AUTO_RUN_ENABLED
- SHELL_EXECUTOR_ENABLED
- DANGEROUS_DEV_MODE
- BYPASS_EVALUATION
- BYPASS_APPROVAL

## Typos to avoid

- TELEGRAM_TOKEN_PLANNE (should be TELEGRAM_TOKEN)
- DATABSE_URL (should be DATABASE_URL)
- DATBASE_URL (should be DATABASE_URL)

## Verification

1. Copy .env.example to .env
2. Set all required variables
3. Ensure dangerous flags are false
4. Run `node --check telebot.js`
5. Start bot and verify /health endpoint
6. Open dashboard at /dashboard
