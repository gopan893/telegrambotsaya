# Inline Button Policy

## Rules
- Max 2 columns
- Button text max 32 chars
- Callback data max 64 chars
- No secrets in callback data
- No direct deploy/push/delete button

## Approval Buttons
- Approve/Reject buttons only for owner
- Proposal ID must be sanitized
- No auto-approve flow

## Keyboard Layout
- Main menu: 2 columns
- Submenus: 2-3 columns with Back button
