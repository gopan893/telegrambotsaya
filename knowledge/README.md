# Knowledge Base Lokal

Masukkan file `.txt`, `.md`, atau `.json` ke folder ini.

Bot akan mengambil potongan informasi yang paling relevan dari folder ini dan menyisipkannya sebagai konteks sebelum menjawab. Cocok untuk:

- Profil bisnis kamu
- Daftar harga
- FAQ
- SOP admin
- Materi belajar
- Catatan pribadi AI
